# PlayNice Exhibition Archive

Use this folder only for campaign assets that do not already have a canonical home elsewhere in /public.

Existing shared assets can stay in:
- /public/hero
- /public/videos
- /public/journal

Recommended structure:
- /public/exhibition/2026/social
- /public/exhibition/2026/stories
- /public/exhibition/2026/hero
- /public/exhibition/2026/film
- /public/exhibition/2025/...

Lifecycle:
- active: campaign is still live; keep published: false
- archived: campaign ended; set published: true
